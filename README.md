# Ticket Resolution Time Prediction

This project uses a Jupyter notebook to explore ticket data and compare regression models that predict how many hours a ticket will take to resolve. The notebook evaluates a simple baseline alongside linear, polynomial, Ridge, and Lasso models.

## Files

- `predict.ipynb` contains the analysis, model comparisons, and visualizations.
- `results_table.csv` contains the model evaluation results.

## Data

To rerun the notebook, place `lab_ticket_resolution.csv` in the project folder. That input dataset is not included here. `results_table.csv` is a summary of model results, not the input dataset.

## Requirements

The notebook uses Python with NumPy, pandas, scikit-learn, and Matplotlib, plus Jupyter to run the notebook.
